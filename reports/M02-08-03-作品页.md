## 2. 三个设计点

### 2.1 路径 id 是唯一可信的作品来源

```java
command.setWorkId(String.valueOf(id));
```

查询参数里也能传 `workId`，但一律被路径 id 覆盖，防止拿 `?workId=2` 看别家作品。

### 2.2 品类胶囊保留作品 id

`/works/1?categoryId=101` —— 品类筛选只叠加，不会丢失作品上下文；切排序、翻页时同样带着 `categoryId`。

### 2.3 二级分类不能当作品打开

`/works/{二级分类id}` 返回 404：`work(id)` 里判断 `parentId != null` 即拒绝，避免出现"作品页里只有一类商品"的怪状态。

## 1. 这次做了什么

新增 71 行样式，覆盖三个页面此前没有样式的结构：

| 区块 | 内容 |
|---|---|
| 列表页 | 两栏布局、侧栏吸顶、类型/排序胶囊按钮、分页禁用态、空结果框 |
| 详情页 | 左图右信息两栏、主图硬阴影、缩略图四列、价格与库存层级 |
| 错误页 | 限宽居中卡片、错误信息红色加粗、两个返回入口 |
| 响应式 | 1000px 与 640px 两个断点 |

## 2. 三个设计点

### 2.1 侧栏吸顶，但单栏时取消

```css
.filters{position:sticky;top:96px}
@media (max-width:1000px){ .filters{position:static} }
```

桌面端滚动时筛选跟着走，`top:96px` 避开吸顶页头；窄屏改单栏后如果继续吸顶会挡住内容。

### 2.2 分页的"不能点"要看得出来

能点的是实线按钮，不能点的是**虚线 + 灰字**：

```css
.pager .disabled{color:#b8ad99;border:2px dashed #d8cdb8}
```

之前第一页的"上一页"和普通文字没区别，用户会去点。

### 2.3 两个断点，各有分工

| 断点 | 处理 |
|---|---|
| ≤1000px | 两栏改单栏、隐藏装饰封面堆叠、详情上下排布 |
| ≤640px | 页头换行、搜索框收窄、标题降字号、缩略图改三列 |

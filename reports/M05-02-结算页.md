## 3. 三个设计点

### 3.1 空车/失效回购物车，而不是错误页

`prepare()` 抛出的 400/409 在 Controller 里被捕获，`redirect:/cart` + flash 提示；
用户看到的下一步就是"处理失效条目"，而不是一张"出了点问题"的页面。POST 路径（M05-03）仍保留 409 错误页。

### 3.2 快照键常量化，M05-03 直接复用

```java
public static final String SNAPSHOT_KEY = "checkoutSnapshot";
```

会话里只存一个键；M05-03 的 POST 按同一个键取快照，避免两边字符串写错。

### 3.3 入口只在"可结算"时出现

购物车页用 `th:if="${cart.settleable}"` 决定给链接还是禁用按钮；
服务端仍会在 `prepare()` 再校验一次——页面禁用只是体验，后端才是防线。

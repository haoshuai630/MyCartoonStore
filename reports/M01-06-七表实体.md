## 1. 这次做了什么

在四个业务模块下建 7 个实体类，字段与列一一对应：

| 模块 | 实体 | 表 |
|---|---|---|
| `cartoon-account` | `StoreUser` | `store_user` |
| `cartoon-catalog` | `Category` / `Product` / `ProductImage` | `category` / `product` / `product_image` |
| `cartoon-cart` | `CartItem` | `cart_item` |
| `cartoon-order` | `SalesOrder` / `SalesOrderItem` | `sales_order` / `sales_order_item` |

## 2. 三条约定

1. **只映射列**：没有任何业务方法、没有计算属性，规则都在 Service。
2. **`category.parent_key` 不映射**：它是数据库生成列，映射进来会诱使有人去写它。
3. **时间与金额类型**：`DATETIME` → `LocalDateTime`，`DECIMAL(12,2)` → `BigDecimal`，`BIGINT` → `Long`，`INT` → `Integer`。

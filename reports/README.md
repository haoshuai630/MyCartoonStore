## 约定

- 汇报与代码在**同一个提交**里，不允许先提交代码后补文档。
- 每个**任务**一份增量汇报（`Mxx-yy-*.md`），每个**模块**一份总汇报（`Mxx-*.md`）。
- 增量汇报必须包含「代码逐行分析」一节；数据脚本按语句块说明。
- 任务清单见 [`docs/tasks/`](../docs/tasks/)，流程规范见 [`docs/10-任务清单与增量汇报规范.md`](../docs/10-任务清单与增量汇报规范.md)。
- 证据文件放在 `reports/evidence/`，命名 `m04-ac08-<描述>.png|sql|log`。

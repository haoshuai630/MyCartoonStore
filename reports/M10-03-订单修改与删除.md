## 1. 这次做了什么

补齐指导书后台「查询、修改、删除订单（Order）和发货」里的后两项：
待支付与待发货订单可以改收货人/电话/地址；已取消订单可以删除（明细一并删）。
金额、明细、支付凭证与状态仍然不可人工编辑，发货仍是唯一的状态迁移入口。

## 4. 关键设计

1. **只改收货三列**：`UPDATE sales_order SET receiver_* WHERE id=?`，金额、明细、状态、凭证、时间列都不在 SET 里。
2. **状态窗口**：修改只允许 `PENDING_PAYMENT`、`PAID`；发货后收货信息随货发出，再改只会让后台与面单不一致。
3. **删除只允许 `CANCELLED`**：已支付及之后是交易凭证；取消时库存已恢复过，删除不再动库存，避免重复加库存。
4. **先删明细再删主表**：`sales_order_item.order_id` 外键指向主表，顺序反了会被挡。
5. **详情页与列表页分工**：修改与删除都放在详情页，列表页只保留查询与发货入口，减少误操作。

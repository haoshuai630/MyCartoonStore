## 2. 三个设计点

### 2.1 只拦明确路径

```java
.addPathPatterns("/cart", "/cart/**", "/orders", "/orders/**", "/profile", "/profile/**")
```

不做"全站拦截 + 白名单"：那要求每个新页面都记得放行，漏一次就把公开页面锁住。现在新增公开页面不用改配置。

### 2.2 原地址带查询串一起编码

```java
String target = request.getRequestURI();
if (request.getQueryString() != null) {
    target = target + "?" + request.getQueryString();
}
```

`/orders?page=2` 登录后能回到第 2 页，而不是只回到 `/orders`。

### 2.3 未登录时不创建会话

```java
HttpSession session = request.getSession(false);
```

取不到就是没登录，不顺手 `getSession()` 新建——否则每次匿名访问都会在内存里留一个空会话。

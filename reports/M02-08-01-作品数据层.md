## 2. 三个设计点

### 2.1 品类是数据，不是代码

"模型/抱枕/其他周边" 都是 `category` 表的二级分类，不在 Java 里写死。以后加"立牌"，只需要在数据库插一行、商品挂上去，代码不动。

### 2.2 周边过滤改成"非单行本"

```xml
<when test="q.productType == 'MERCH'">AND c.code NOT LIKE '%-COMIC'</when>
```

原来写死 `%-MERCH`，加了模型/抱枕就漏；现在任何非 COMIC 的二级分类都算周边。

### 2.3 作品统计一条 SQL

```sql
(SELECT COUNT(*) FROM product pr JOIN category c2 ON pr.category_id = c2.id
  WHERE c2.parent_id = p.id AND pr.status = 'ON_SALE') AS product_count
```

作品墙 5 张卡，如果用循环查就是 11 次往返；现在一次查完。下架商品不计入数字。

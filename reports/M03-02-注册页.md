## 2. 三个设计点

### 2.1 两次密码一致放在控制器

格式与唯一性属于账号规则，放 `AccountService`；"两次输入是否一致"是表单层面的问题，Service 不该知道有两个密码框。所以只在控制器比对。

### 2.2 成功后不自动登录

```java
redirect.addFlashAttribute("message", "注册成功，" + created.getUsername() + "，请登录");
return "redirect:/login";
```

让用户用刚设的密码登一次，顺便验证密码记对了；也避免注册接口顺带建立会话。

### 2.3 失败回填已填内容

```java
model.addAttribute("username", username);
model.addAttribute("displayName", displayName);
```

只回填用户名与显示名，**密码不回填**——刷新或后退时浏览器不应还留着刚输入的密码。

## 2. 三个设计点

### 2.1 素材路径与数据库严格对齐

数据库里存的是 `images/products/{sku}/cover.svg`，生成器就按这个路径落盘。页面用 `th:src="@{/images/products/...}"`，不需要在模板里拼字符串，也不会出现"库里有路径、磁盘没文件"。

### 2.2 布局先跑通，再填数据

M02-02 的 `main.html` 只保证页头、页脚、样式、字体、按钮样式正确；作品入口与两个商品栏目留给 M02-03。这样布局问题和数据问题分开定位。

### 2.3 片段用参数化标题

```html
<head th:fragment="head(title)">
    <title th:text="${title} + ' | 漫屿 MANGA ISLE'">漫屿</title>
```

页面只需 `th:replace="~{fragments/common :: head('首页')}"`，标题格式统一。

## 3. 两个 Boot 4 / Thymeleaf 3.1 的坑

### 3.1 `@AutoConfigureMockMvc` 换了包名

Boot 4 把它挪到了 `org.springframework.boot.webmvc.test.autoconfigure`，并且需要显式加依赖：

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-webmvc-test</artifactId>
    <scope>test</scope>
</dependency>
```

### 3.2 Thymeleaf 3.1 移除了 `#request`

原来想写 `${#request.getAttribute('loginName')}` 显示登录名，启动测试直接抛：

```
Exception evaluating SpringEL expression
```

改成固定「游客」，等 M03 接入 Session 后再用模型属性。

## 1. 交付内容

| 能力 | 路径 / 类 | 说明 |
|---|---|---|
| 注册 | `/register` | 用户名唯一、BCrypt 散列、两次密码一致校验 |
| 登录 | `/login` | 会话写入 `userId` 与 `displayName`，支持站内回跳 |
| 登出 | `/logout` | POST，清空会话 |
| 拦截 | `LoginInterceptor` | 未登录访问 `/cart`、`/orders`、`/profile` 跳登录 |
| 页头 | `fragments/common.html` | 已登录显示名字与退出，未登录显示登录/注册 |

## 2. 关键决策

| 决策 | 原因 |
|---|---|
| 只引 `spring-security-crypto` | 只要 BCrypt，不引入整个 Spring Security |
| 登录失败不区分原因 | 防止用错误提示枚举账号 |
| 禁用账号单独 403 | 密码已对，拒绝原因是状态，可以明说 |
| 会话只存两个值 | 不把实体与密码哈希带进会话 |
| 拦截器只列受保护路径 | 新增公开页面不用改配置 |
| 回跳只接受站内相对路径 | 防开放重定向 |
| 注册成功不自动登录 | 让用户用新密码登一次，顺便验证记对了 |

## 3. 踩过的坑

| 问题 | 处理 |
|---|---|
| Mockito 在 JDK 27 初始化失败 | 模块级 `mockito-extensions/MockMaker` = `mock-maker-subclass` |
| M03 分支缺 M02 的验收工具 | 从 M02 分支单独取 `db/tools`，避免整分支合并的报告冲突 |
| 页头片段外层 div 影响吸顶 | 保持 `display:contents` |

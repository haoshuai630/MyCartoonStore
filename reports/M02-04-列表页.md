## 2. 四个设计点

### 2.1 筛选条件用链接，不用表单

类型和排序都是 `<a>`，链接里带上其它参数。好处是：翻页、搜索、切类型时参数不会丢；浏览器前进后退也正常。

### 2.2 分页按钮由 PageResult 判断

```html
<a th:if="${page.hasPrevious()}" ...>上一页</a>
<span th:unless="${page.hasPrevious()}" class="disabled">上一页</span>
```

模板不算 `page > 0`，判断集中在 `PageResult`，第一页/最后一页不会出现可点的死链接。

### 2.3 参数错误必须是 400，不是 500

之前 `BizException` 直接冒到容器，浏览器看到的是 Whitelabel 500。加了 `GlobalExceptionHandler`：

```java
response.setStatus(e.code() == ErrorCode.NOT_FOUND ? 404 : 400);
```

这样 `?sort=PRICE` 得到 400 + 可读错误页，测试也能断言状态码。

### 2.4 空结果给可操作提示

```html
<p class="empty" th:if="${page.isEmpty()}">没有符合条件的商品，换个条件试试。</p>
```

## 怎么看提交

| 想看什么 | 地址 |
|---|---|
| 分支的提交列表 | `https://github.com/haoshuai630/MyCartoonStore/commits/feat/m01-db` |
| 某次提交改了什么 | `https://github.com/haoshuai630/MyCartoonStore/commit/<sha>` |
| 分支与 main 的差异 | `https://github.com/haoshuai630/MyCartoonStore/compare/main...feat/m01-db` |
| 本地 | `git log --oneline --decorate --graph --all` |

> GitHub 首页的文件列表页只显示"每个文件最后一次改动"，不是提交列表；
> 要点文件列表右上角的 `N Commits`，或用上面的地址。

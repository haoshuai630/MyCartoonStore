## 2. 四个设计点

### 2.1 数量上限写在控制器常量里

```java
private static final int NEWEST_LIMIT = 3;
private static final int FEATURED_LIMIT = 4;
```

模板里不出现魔法数字，改口径只改一处；也方便和 01 篇 FR-G-01 对照。

### 2.2 空状态是页面的一部分，不是异常

```html
<p th:if="${#lists.isEmpty(newest)}">暂无上架商品。</p>
```

空库时首页仍然 200，显示空文案；不会因为 `null` 抛模板异常。

### 2.3 下架商品在 SQL 层就被过滤

`selectNewest` / `selectFeatured` 的 SQL 都带 `status = 'ON_SALE'`，模板不做二次判断——避免"有一处忘了判断"导致下架商品漏出。

### 2.4 价格用 Thymeleaf 数字格式化

```html
th:text="'¥' + ${#numbers.formatDecimal(p.price, 1, 2)}"
```

`28` 渲染成 `¥28.00`，与 01 篇"人民币两位小数"一致；不在 Java 侧拼字符串。

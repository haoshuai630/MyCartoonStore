## 2. 四个设计点

### 2.1 会话只放两个值

```java
session.setAttribute("userId", user.getId());
session.setAttribute("displayName", user.getDisplayName());
```

不放整个实体：Session 序列化开销小、也不会把密码哈希带到会话里。

### 2.2 回跳地址必须校验

```java
if (redirect == null || !redirect.startsWith("/") || redirect.startsWith("//")) {
    return "/main";
}
```

只接受站内相对路径；`//evil.example.com` 这种会被当成协议相对地址跳到站外，必须一起拒掉。

### 2.3 登出用 POST

GET 会被浏览器预取、被链接扫描器触发，用 POST 避免"点了个链接就被登出"。

### 2.4 登录失败留在原页

失败不重定向，直接回渲染登录页并带上错误与已填用户名；密码框始终为空。

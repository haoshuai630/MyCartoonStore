## 2. 这次做了什么

管理端从"只有探活接口"变成"能安全登录、有控制台"：

- **门禁**：`AdminAuthInterceptor` 拦住 `/admin/**`，黑白名单反过来写——全站受保护，只放行 `/login`、`/logout`、`/health`、静态资源与错误页。以后新增管理页默认就是受保护的。
- **登录**：`GET/POST /admin/login`，只接受启用 `ADMIN`；失败回表单并显示统一文案；成功换会话 ID 后写入 `userId` 与 `displayName`；`POST /admin/logout` 销毁会话。
- **控制台**：`GET /admin`（含 `/admin/`）显示当前管理员与三个业务入口；入口未接入前显示"待接入（M07-04/06/08）"，不放点了会 404 的链接。
- **样式与错误页**：`admin.css`（纸色 + 墨色 + 硬阴影，无前端框架）、`admin/fragments.html` 公共片段、`error/error.html` 业务异常页。
- **测试基座**：`AdminIntegrationTest`（真实 MySQL + 每例重建表）、`AdminFixture`、`application-test.yaml`；`AdminLoginTest` 12 例。

**没有做的**：分类/商品/订单页面（M07-04/06/08）、CSRF（M09）、用户启停与相册（M08）。

## 3. 关键设计

### 3.1 管理端用"全站拦截 + 白名单"，用户端相反

用户端页面多且会不断增加，逐个列受保护路径更直观；管理端只有后台页，**漏登记等于默认开放**，所以反过来写：
`/**` 全拦，只放行登录、退出、探活、静态资源和错误页。新增一个管理页不需要改配置。

### 3.2 门禁不做业务判断

拦截器只回答"这个人现在能不能进后台"（存在 + ADMIN + ENABLED），
分类层级、商品版本、订单状态都不在这里；这样以后调业务规则不会碰到门禁。

### 3.3 会话 ID 用 `changeSessionId()` 轮换

docs/02 §6.2 写的是"invalidate 后新建"。实际实现用 Servlet 3.1 的 `changeSessionId()`：
登录前的会话 ID 立即作废、属性保留、无需在两个会话对象之间搬数据；
在 MockMvc 下也可测（`invalidate()` 后再 `getSession(true)` 在 mock 容器里会拿到已失效的会话对象，测试反而失真）。
效果与"重建会话"一致，差异记在这里，不改文档。

### 3.4 重定向目标要去掉 context-path

`GET /admin/categories` 被拦时，若直接把 `request.getRequestURI()`（`/admin/categories`）塞进 `redirect`，
登录后 Spring 再拼一次 context-path 就变成 `/admin/admin/categories`。
所以 `insidePath()` 先减掉 `/admin`，只存 `/categories`。

### 3.5 入口"待接入"而不是死链

docs/05 §1.4 要求"没有实现的能力不出现按钮"。三个业务入口在 M07-04/06/08 才接上，
本任务用虚线的"待接入"卡片说明用途，既让控制台像后台，也不制造点了打不开的链接。

| 操作 | 实际结果 |
|---|---|
| `GET /admin/login` | 200，页面含「管理员登录」「只接受管理员账号」 |
| 未登录 `GET /admin/` | 302 → `/admin/login?redirect=/` |
| `POST /admin/login`（admin / Cartoon123!） | 302 → `/admin/`，并下发 `CARTOON_ADMIN_SESSION` |
| 登录后 `GET /admin/` | 200，含「控制台」「admin」「待接入」 |
| `GET /admin/css/admin.css` | 200（静态资源免登录） |
| `POST /admin/login`（alice 顾客 / carol 停用） | 200，同一句「账号或密码错误，或账号不可用」，**不下发会话 Cookie** |

| 用例 | 断言 |
|---|---|
| `loginPageRenders` | 登录页 200，文案标明管理员入口 |
| `loggedInAdminGoesToConsole` | 已登录访问登录页 → 302 `/` |
| `loginSucceeds` | 302 `/`，会话写入 `userId` / `displayName` |
| `customerCannotLogIn` / `disabledAdminCannotLogIn` / `wrongPassword` | 200 + 统一文案；失败不建会话 |
| `consoleRequiresLogin` | 未登录 → 302 `/login?redirect=%2F` |
| `consoleRendersForAdmin` | 200，含控制台、当前管理员、待接入入口 |
| `customerSessionRejected` | 顾客会话被拒且会话作废（AC-05） |
| `disabledAfterLoginRejected` | 登录后停用 → 立即被拒（AC-07） |
| `logoutClearsSession` | 302 `/login` 且会话作废 |
| `cssIsOpen` | 静态资源免登录 |

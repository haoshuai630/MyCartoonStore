## 1. 交付内容

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | `/main` | 作品入口 + 新品 3 + 精选 4 |
| 作品墙 | `/works` | 5 部作品卡片，带品类数与在售数 |
| 作品页 | `/works/{id}` | 横幅 + 10 个品类胶囊 + 排序 + 分页 |
| 全部商品 | `/category` | 作品下拉 + 类型 + 排序 + 关键字 + 分页 |
| 商品详情 | `/product/{id}` | 面包屑、相册、购买区（购物车占位） |

数据层：`CatalogService`（搜索、详情、作品、分类树）+ `WorkSummary` / `WorkDetail` / `ProductDetail`。
素材：95 张封面 + 160 张相册图，全部脚本生成。

## 2. 关键决策

| 决策 | 原因 |
|---|---|
| 三层导航（作品墙 → 作品页 → 商品） | 侧栏列 IP 会随 IP 数增长，不可用 |
| 品类按行业口径（徽章/立牌/挂件/纸制品/镭射票/毛绒/手办/画集/服装/文具） | 谷圈与电商通行分类，能覆盖真实商品 |
| 参数校验集中在 Service | Controller 不解析参数，只有一处把脏输入变 400 |
| 下架与不存在统一 404 | 不泄露"存在但下架" |
| 商品类型过滤用 `NOT LIKE '%-COMIC'` | 新增品类不用改 SQL |

## 3. 踩过的坑

| 问题 | 处理 |
|---|---|
| Mockito 在 JDK 27 初始化失败 | 加 `mockito-extensions/MockMaker` = `mock-maker-subclass` |
| Boot 4 `@AutoConfigureMockMvc` 换包 | 加 `spring-boot-webmvc-test` 依赖 |
| Thymeleaf 3.1 移除 `#request` | 游客身份先写死，M03 接 Session |
| 页头吸顶失效 | fragment 外层 div 与内容等高，加 `display:contents` |
| 品类 id 与下一部作品相撞 | 偏移改为 1–10，脚本改为可重复导入 |

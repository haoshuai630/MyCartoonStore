## 手工验收中发现并修复的问题

| 现象 | 根因 | 修复 |
|---|---|---|
| AC-28 脚本输出 `RESULT: FAIL`，但库存与订单都正确 | `urllib` 自动跟随 302，`status` 是最终 200 而不是 3xx | 判据改为最终 URL 与订单数量；重跑 PASS |
| 两端 403 响应体为空（MockMvc 断言文案失败） | MockMvc 不做容器错误分发 | 拆成"状态码断言"与"错误视图渲染断言"两条 |
| 管理端「顾客不能登录」用例失败 | 原断言"失败后无会话"，而 CSRF 令牌需要会话 | 改断言"会话里没有 `userId`" |
| AC-32 证据文件被后一步覆盖 | 最初五个步骤共用同一个输出文件 | 改成按步骤分文件（`1-backup`…`5-restore`） |
| 用 PowerShell 改含中文的脚本导致乱码 | `Get-Content`/`Set-Content` 默认编码非 UTF-8 | 用 Python 处理；损坏文件重写 |

## 2. 三个设计点

### 2.1 用会话判断，不查库

```html
<span th:if="${session.userId == null}">
```

页头每个页面都渲染，不能在这里查库；登录时已把 `userId` 与 `displayName` 放进会话。

### 2.2 退出是 POST 表单

GET 退出会被预取、被链接扫描器触发。做成一个小表单，样式按链接显示。

### 2.3 保留吸顶所需的 `display:contents`

页头片段外层那层 div 不能加边框或高度，否则 `position: sticky` 又会失效——之前踩过一次。

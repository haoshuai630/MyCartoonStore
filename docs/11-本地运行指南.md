## 2. 初始化数据库（只需一次）

```powershell
# 在仓库根目录执行
mysql -u root -p --default-character-set=utf8mb4 < db/02-schema-with-demo.sql
```

执行完核对：

```sql
USE MyCartoonStore;
SELECT
  (SELECT COUNT(*) FROM store_user)       AS users,      -- 4
  (SELECT COUNT(*) FROM category)         AS categories, -- 15
  (SELECT COUNT(*) FROM product)          AS products,   -- 60
  (SELECT COUNT(*) FROM product_image)    AS images,     -- 100
  (SELECT COUNT(*) FROM cart_item)        AS carts,      -- 0（M01-04 才有）
  (SELECT COUNT(*) FROM sales_order)      AS orders,     -- 0（M01-04 才有）
  (SELECT COUNT(*) FROM sales_order_item) AS items;      -- 0（M01-04 才有）
```

> 两个脚本二选一：`01-schema.sql` 只有结构，`02-schema-with-demo.sql` 带演示数据。
> **不要依次执行**，两个都含建表语句。

数据库连接配置在：

- `cartoon-user-web/src/main/resources/application.yaml`
- `cartoon-admin-web/src/main/resources/application.yaml`

默认 `root` / `${DB_PASSWORD:123456}`。口令不同就改这里，或设环境变量 `DB_PASSWORD`。

## 3. 构建

```powershell
# 全量打包（跳过测试，快）
.\mvnw.cmd -DskipTests package

# 只构建用户端及其依赖
.\mvnw.cmd -pl cartoon-user-web -am -DskipTests package
```

首次执行 `mvnw` 会下载 Maven 发行包（约 10 MB），之后走本地缓存。

---

## 4. 启动

### 方式 A：命令行（两个终端各一个）

```powershell
# 终端 1：用户端 8080
.\mvnw.cmd -pl cartoon-user-web spring-boot:run

# 终端 2：管理端 8081
.\mvnw.cmd -pl cartoon-admin-web spring-boot:run
```

### 方式 B：直接跑打好的 jar

```powershell
java -jar cartoon-user-web\target\cartoon-user-web-0.1.0-SNAPSHOT.jar
java -jar cartoon-admin-web\target\cartoon-admin-web-0.1.0-SNAPSHOT.jar
```

### 方式 C：IDEA（推荐）

**① 打开项目：认准根目录的 `pom.xml`**

`File → Open` → 选仓库根目录的 `pom.xml` → 弹窗选 **Open as Project**（不要选 Open as File）。

打开后左侧 Project 面板应该是：

```
mycartoonstore
├── cartoon-common
├── cartoon-catalog
├── cartoon-account
├── cartoon-cart
├── cartoon-order
├── cartoon-payment
├── cartoon-test-support
├── cartoon-user-web
└── cartoon-admin-web
```

如果只看到 `cartoon-user-web` 一个目录，说明打开的是子模块，关掉重开根 `pom.xml`。

**② 等 Maven 导入完**

右下角进度条走完；Maven 工具窗口里 9 个模块都应该是蓝色（不是灰色）。

**③ 确认 JDK**

`File → Project Structure → Project`：

- **SDK**：选 17 以上的 JDK（本机是 `E:\IDEA\jdk-27`）
- **Language level**：与 SDK 一致

`pom.xml` 里写的是 `<java.version>27</java.version>`，SDK 低于 27 会报 `release version 27 not supported`。

**④ 直接运行两个启动类**

在 Project 面板里找到：

- `cartoon-user-web/src/main/java/org/csu/mycartoonstore/web/CartoonUserApplication.java`
- `cartoon-admin-web/src/main/java/org/csu/mycartoonstore/admin/CartoonAdminApplication.java`

右键 → **Run**，或点行号旁的绿色三角。第一次运行 IDEA 会自动生成 Spring Boot 运行配置。

两个都要跑就再点一次另一个，`Services` 窗口里会并排显示两个进程（端口 8080 / 8081）。

**⑤ 验证**

浏览器打开 <http://localhost:8080/health>，看到 `mycartoonstore-user ok` 即成功。

**IDEA 里容易踩的三个坑**

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动类旁边没有绿三角 | 模块没被识别成源码根 | 右键 `src/main/java` → `Mark Directory as → Sources Root` |
| `Cannot resolve org.csu.mycartoonstore:cartoon-common` | 只导入了子模块 | 重新打开根 `pom.xml`，或 Maven 面板点 Reload |
| 控制台报 `release version 27 not supported` | Project SDK 太低 | Project Structure 换 27（或把 pom 的 `java.version` 改成你装的版本） |

> 提示：`cartoon-user-web` 与 `cartoon-admin-web` 都带 `spring-boot-devtools`，M02 之后改模板保存即刷新，不用重启。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Port 8080 was already in use` | 上一次没退干净 | `netstat -ano | findstr :8080` 找 PID，`taskkill /PID <pid> /F` |
| `Access denied for user 'root'` | 口令不对 | 改 `application.yaml` 的 `password`，或设 `DB_PASSWORD` |
| `Unknown database 'MyCartoonStore'` | 没初始化 | 执行第 2 步 |
| 启动报 `Table 'xxx' doesn't exist` | 用了 `01-schema.sql` 但没数据/表未建全 | 空库重跑 `02` |
| `Unsupported class file major version` | JDK 版本过低 | 换 17+ 的 JDK，检查 `JAVA_HOME` |
| `mvnw` 卡在下载 | 网络慢 | 用本机 `mvn` 代替 `.\mvnw.cmd` |
| 页面 404 | 正常，页面未实现 | 等 M02 |

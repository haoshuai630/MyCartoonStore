## 任务详情

### M02-01 查询服务与参数校验

- **目标**：把"页面查什么"收敛成一个服务，所有非法参数在服务层转成 400。
- **产出**：
  - `cartoon-common`：`PageResult<T>`（items/total/page/pageSize/totalPages）
  - `cartoon-catalog`：`CatalogService`、`ProductSearchCommand`、`ProductDetail`
- **规则**：
  - `productType ∈ {ALL, COMIC, MERCH}`，其他 → 400
  - `sort ∈ {DEFAULT, PRICE_ASC, PRICE_DESC, NEWEST}`，其他 → 400
  - `keyword` 去首尾空白、≤120 字符，`%` `_` `\` 转义后再进 LIKE
  - 分页复用 `PageQuery`（页码归一、页大小 1–50）
  - 详情：不存在或 `DRAFT` → 404「商品不存在或已下架」
- **验收**：`mvn -pl cartoon-catalog test` 全绿；非法参数各有对应用例。

### M02-02 公共布局与静态资源

- **目标**：抽出页头/页脚/导航/提示条，建立 CSS 与素材。
- **产出**：`templates/fragments/*.html`、`static/css/store.css`、`static/images/**`
- **规则**：
  - 页头含品牌、导航、搜索框、购物车徽标（游客显示 0）
  - 素材用项目自制 SVG，按 `images/products/{sku}/cover.svg` 命名
- **验收**：随便一个页面能渲染出完整布局，无 404 资源。

### M02-03 首页 `/main`

- **目标**：5 部作品入口 + 新品 3 + 精选 4。
- **验收**：与种子数据核对——新品是 CICADA-M04 / ONIGIRI-C04 / MISTPORT-M05，精选是 STARLINE-C01 / MISTPORT-C01 / IRONWOOD-M01 / CICADA-C05。

### M02-04 列表 `/category`

- **目标**：分类侧栏 + 类型按钮 + 排序 + 关键字 + 分页。
- **规则**：切换任一条件回第 1 页；无结果显示清空筛选；非法参数 400；分类不存在 404。
- **验收**：一级分类含其下两个二级；二级不串类；翻页保留条件。

### M02-05 详情 `/product/{id}`

- **目标**：单 SKU 详情、分类路径、相册、库存、数量入口。
- **规则**：相册按 `sort_order, id`；无相册回退封面；零库存显示售罄；DRAFT/不存在 404。
- **验收**：三个样例——有相册、无相册、零库存。

### M02-06 页面测试与状态

- **目标**：MockMvc 验证路由、状态码、渲染内容与空/错状态。
- **验收**：至少覆盖首页 200、列表 200/400/404、详情 200/404、空结果页。

### M02-07 模块收尾

- **目标**：全量 verify、总汇报、合并 `main`、打 `v0.4-m02`。

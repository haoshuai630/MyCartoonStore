# M02-08 任务清单 · 作品墙与作品页

> 背景：列表页侧栏把"作品"当筛选器，IP 越多越长。改为三层导航：作品墙 → 作品页 → 商品；侧栏取消。

## 页面层级

| 路径 | 页面 | 主要内容 |
|---|---|---|
| `/works` | 作品墙 | 所有作品卡片：封面、名称、简介、品类数、商品数 |
| `/works/{id}` | 作品页 | 作品横幅 + 品类胶囊（该作品的二级分类）+ 排序 + 商品网格 + 分页 |
| `/category` | 全部商品 | 单栏：作品下拉 + 品类胶囊 + 排序 + 关键字；不再有侧栏 |

导航栏改为：首页 / 作品 / 全部商品 / 我的订单。

## 数据口径

| 概念 | 数据库 | 说明 |
|---|---|---|
| 作品 | `category.parent_id IS NULL` | 一级分类 |
| 品类 | `category.parent_id = 作品id` | 二级分类：单行本、模型、抱枕… |
| 作品的全部商品 | `product.category_id IN (该作品的所有二级分类)` | 需要新增按作品过滤的 SQL |

## 验收口径

| 用例 | 断言 |
|---|---|
| 作品墙 | 200，出现全部作品名与"共 N 部" |
| 作品页 | 200，只出现该作品商品，不出现别家 |
| 作品页品类筛选 | 点"模型"只剩模型，单行本消失 |
| 作品页 404 | 不存在的作品 id 返回 404 |
| 列表页 | 侧栏消失，作品下拉能切作品 |

## 风险

| 风险 | 处理 |
|---|---|
| 作品过滤 SQL 要兼容分页与排序 | 复用现有 `ProductQuery`，只加一个 `workId` 条件 |
| 现有测试引用了侧栏文案 | 改 `CategoryPageTest` 与 `HomePageTest` 的断言 |
| 品类目前只有"单行本/周边" | 数据层支持任意二级分类，M07 后台可维护；演示数据可加"模型/抱枕" |

# M03 任务清单 · 账号与权限

> 目标：能注册、能登录、能登出；未登录访问受保护页面会被拦到登录页；页头显示当前身份。

## 范围

| 能做 | 不做（留到后续模块） |
|---|---|
| 注册（用户名唯一、BCrypt 存密码） | 找回密码、改密码 |
| 登录 / 登出（Session） | 第三方登录 |
| 禁用账号拒绝登录 | 角色权限细分（管理端在 M07） |
| 未登录拦截 `/cart`、`/orders`、`/profile` | 记住我、验证码 |

## 数据

只用 `store_user`：`username`（唯一）、`password_hash`（BCrypt）、`display_name`、`role`、`status`。

种子数据里 4 个用户口令都是 `Cartoon123!`，`carol` 是 `DISABLED`，用来验证"禁用账号不能登录"。

## 任务拆分

| 编号 | 任务 | 产物 | 预计 | 状态 |
|---|---|---|---|---|
| M03-01 | 账号数据层与密码服务 | `AccountService`、`PasswordEncoder` 配置、单测 | 2h | ⬜ |
| M03-02 | 注册页 `/register` | `RegisterForm`、`register.html`、校验与唯一性 | 2h | ⬜ |
| M03-03 | 登录 / 登出 | `LoginForm`、`login.html`、Session 存取 | 2h | ⬜ |
| M03-04 | 登录拦截器 | `LoginInterceptor`、注册拦截路径、回跳参数 | 1.5h | ⬜ |
| M03-05 | 页头身份显示 | 公共片段显示用户名/登录入口、登出按钮 | 1h | ⬜ |
| M03-06 | 测试与收尾 | MockMvc 用例、README/进度同步、模块汇报 | 1.5h | ⬜ |

合计约 **10h**。

## 验收口径

| 用例 | 断言 |
|---|---|
| 注册成功 | 新用户写入库，密码是 BCrypt 哈希而非明文 |
| 用户名重复 | 返回注册页并提示，不覆盖已有账号 |
| 密码错误 | 停留在登录页并提示，不建立会话 |
| 禁用账号 | `carol` 登录被拒，提示账号已停用 |
| 登录成功 | Session 里有用户 id，页头显示名字 |
| 未登录访问 `/cart` | 302 到 `/login?redirect=/cart`，登录后回跳 |
| 登出 | Session 清空，再访问受保护页又被拦 |

## 设计约定

- 密码只在 Service 里用 `BCryptPasswordEncoder` 校验，控制器不碰哈希
- Session 里只存 `userId` 与 `displayName`，不放整个实体
- 拦截器只拦明确的受保护路径，不做"全站拦截后放行白名单"，避免以后新增页面忘记配
- 错误提示统一走同一个错误页/表单提示，不把"用户名不存在"和"密码错误"分开（防枚举）

## 风险

| 风险 | 处理 |
|---|---|
| 现有测试不期望登录 | 受保护页面在测试里先登录再请求，或走拦截器放行配置 |
| 页头片段改动影响所有页面 | 片段里用 `session` 判断，未登录显示"登录" |
| BCrypt 在 JDK 27 下的兼容 | 用 Spring Security Crypto 的 `BCryptPasswordEncoder`，不引整包 |

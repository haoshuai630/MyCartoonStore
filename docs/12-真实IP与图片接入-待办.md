## 3. 图片方案

| 方案 | 做法 | 取舍 |
|---|---|---|
| 外链引用 | `cover_image` 存 `https://...` | 仓库里只有链接，不构成再分发；依赖对方图床 |
| 取色生成 | 下载参考图 → Pillow 取主色 → 生成 SVG | 只借鉴配色，不复刻画面；需要临时下载 |
| 自绘占位 | 现有 `gen_assets.py` | 无版权风险，但一看就是图形 |

**决定**：真实图只放少量（每部 1 张封面 + 2–3 张周边），用外链；其余用取色生成的 SVG 占位；相册沿用自绘。

## 5. 版权口径

- 非商业教学演示，风险低；但仓库是公开的，**图片不入库、只存外链**
- 商品图权利多在厂商或拍摄方，平台图常有店铺水印
- 取色生成只借鉴配色，不复刻画面
- 下载仅用于取色时，用完即删，不提交

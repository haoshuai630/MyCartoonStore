# 04 · 接口设计说明书

> 本项目是服务端渲染，没有 JSON API。这里的"接口"指**路由契约**：URL、方法、参数、校验、状态码、渲染模板。
> 实验二的 REST API 另立设计，本期不实现。

---

## 1. 通用约定

| 项 | 约定 |
|---|---|
| URL | 全小写，不带 `.html` 后缀；资源用路径参数（`/product/{id}`） |
| 方法 | 查询用 `GET`；所有状态变更（登录提交、加车、下单、支付、取消、发货、上下架、启停）用 `POST` |
| 编码 | UTF-8 |
| 会话 | `CARTOON_USER_SESSION` / `CARTOON_ADMIN_SESSION`，30 分钟无操作失效；**只允许 Cookie 跟踪**，URL 不出现 `;SESSION=` |
| CSRF | 所有 `POST/PUT/PATCH/DELETE` 必须带隐藏域 `_csrf`，否则 403 + `error/403.html`（M09-02 起启用；读请求由过滤器签发令牌，写表单统一由 `fragments/csrf.html` 渲染） |
| 重定向 | 写操作成功后 **POST/Redirect/GET**，避免刷新重复提交 |
| 未登录 | 受保护页面 302 到本端登录页，登录后回原页；**登录后不自动重放写请求**。写请求先过 CSRF：无令牌 403，令牌合法但未登录才 302 |
| 参数错误 | 400 + `error/400.html`，说明具体参数与返回入口 |
| 越权 | 404 + 错误页，不泄露目标对象是否存在（与"不存在"同码同文案） |
| 不存在/下架 | 404 + `error/404.html` |
| 冲突 | 409 + 提示"数据已变化，请刷新后重试" |
| 技术异常 | 500 + `error/500.html`，不输出 SQL、堆栈、密码 |

### 1.1 参数校验顺序

```
① 格式（能否解析） → ② 范围（枚举/长度/数值区间） → ③ 存在性 → ④ 归属 → ⑤ 状态 → ⑥ 业务规则
```

任一步失败立即返回，不继续执行后续查询（避免越权探测）。

## 2. 用户端路由（:8080）

### 2.1 浏览

| 方法 | 路径 | 参数 | 说明 | 模板 |
|---|---|---|---|---|
| GET | `/` `/index` | — | 直接渲染首页（欢迎页已取消，见 FR-G-00） | `main.html` |
| GET | `/main` | — | 首页：新品 3 + 精选 4 + 5 个作品入口 | `main.html` |
| GET | `/category` | `categoryId` `productType` `sort` `keyword` `page` `pageSize` | 列表与搜索 | `category.html` |
| GET | `/product/{id}` | — | 商品详情 | `product.html` |
| GET | `/works` | — | 作品墙：5 部作品入口 | `works.html` |
| GET | `/works/{id}` | — | 作品页：横幅 + 品类胶囊 + 该作品商品（不存在 404） | `work.html` |

`/category` 参数规则：

| 参数 | 缺省 | 合法值 | 非法处理 |
|---|---|---|---|
| `categoryId` | 空 = 全部 | 存在的分类 ID | 格式错 → 400；合法但不存在 → 404「分类不可用」 |
| `productType` | `ALL` | `ALL` `COMIC` `MERCH` | 其他 → 400 |
| `sort` | `DEFAULT` | `DEFAULT` `PRICE_ASC` `PRICE_DESC` `NEWEST` | 其他 → 400 |
| `keyword` | 空 | 去空白后 ≤120 字符 | 超长 → 400；`%` `_` 按普通字符 |
| `page` | 1 | ≥1 整数 | 非整数/溢出 → 400；<1 → 归一为 1 |
| `pageSize` | 6 | 1–50 整数 | 越界/格式错 → 400 |

> 类型过滤与分类的联动：选了 `categoryId` 时，`ALL` 取该一级下两个二级的并集；未选时跨 5 部作品。

### 2.2 账号

| 方法 | 路径 | 参数 | 说明 | 模板 |
|---|---|---|---|---|
| GET | `/register` | — | 注册页 | `auth/register.html` |
| POST | `/register` | `username` `displayName` `password` `confirmPassword` `captcha` `_csrf` | 注册；成功 302 `/login`，格式错或重名时 200 回表单并提示 | `auth/register.html` |
| GET | `/login` | `redirect` | 登录页（`redirect` 用于登录后回跳） | `auth/login.html` |
| POST | `/login` | `username` `password` `redirect` `captcha` `_csrf` | 登录；成功 302 `redirect`，失败 200 回显用户名 | `auth/login.html` |
| POST | `/logout` | `_csrf` | 退出，销毁本端 Session | 302 `/main` |
| GET | `/profile` | — | 个人资料（P1） | `profile.html` |
| POST | `/profile` | `displayName` `email` `phone` `_csrf` | 保存资料（P1） | 302 |
| GET | `/password` | — | 修改密码（P1） | `password.html` |
| POST | `/password` | `oldPassword` `newPassword` `confirmPassword` `_csrf` | 改密（P1） | 成功销毁会话→`/login` |

`redirect` 只接受以 `/` 开头且不以 `//` 开头的站内路径，其余回退 `/main`。
拦截器跳登录页时写入 `?redirect=`：GET 用原地址，POST 取同源 `Referer` 的路径（非同源则回首页），
因此登录后不会重放写请求。

### 2.3 购物车

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/cart` | — | 本人购物车，含失效条目提示 |
| POST | `/cart/items` | `productId` `quantity` `_csrf` | 加入（同商品累加） |
| POST | `/cart/items/{itemId}/quantity` | `quantity` `version` `_csrf` | 改数量（1–99） |
| POST | `/cart/items/{itemId}/remove` | `version` `_csrf` | 移除 |
| GET | `/checkout` | — | 生成临时确认并渲染确认页；车空 302 回 `/cart` |
| POST | `/checkout` | `receiverName` `receiverPhone` `receiverAddress` `_csrf` | 提交订单 |

### 2.4 订单与支付

| 方法 | 路径 | 参数 | 说明 | 模板 |
|---|---|---|---|---|
| GET | `/orders` | `status` `orderNo` `page` `pageSize` | 本人订单列表 | `orders.html` |
| GET | `/orders/{orderNo}` | — | 订单详情（校验归属） | `order.html` |
| POST | `/orders/{orderNo}/cancel` | `_csrf` | 取消待支付 | 302 详情 |
| POST | `/orders/{orderNo}/complete` | `_csrf` | 确认收货（P1） | 302 详情 |
| GET | `/payment/{orderNo}` | — | 模拟支付页 | `payment.html` |
| POST | `/payment/{orderNo}/success` | `_csrf` | 模拟成功 | 302 详情 |
| POST | `/payment/{orderNo}/failure` | `_csrf` | 模拟失败 | 302 支付页 |

`/orders` 参数：`status` 缺省 `ALL`，只接受五种状态 + `ALL`；`orderNo` 去空白 ≤40 字符精确匹配；`pageSize` 缺省 10。

## 3. 管理端路由（:8081，context-path=`/admin`）

### 3.1 登录

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/admin/login` | — | 管理端登录页 |
| POST | `/admin/login` | `username` `password` `_csrf` | 只接受启用的 ADMIN |
| POST | `/admin/logout` | `_csrf` | 退出 |
| GET | `/admin` | — | 控制台：当前管理员 + 四个导航入口（分类 / 商品 / 订单 / 顾客） |

### 3.2 分类

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/admin/categories` | `keyword`（M07-10 追加） | 按作品折叠（默认收起）；`keyword` 对一级作品名或编码做包含匹配（去空白、≤50），命中作品默认展开 |
| GET | `/admin/categories/new` | `parentId`（可选） | 新增表单；带 `parentId` 即新增二级 |
| POST | `/admin/categories` | `code` `name` `parentId` `sortOrder` `_csrf` | 新增 |
| GET | `/admin/categories/{id}/edit` | — | 编辑表单 |
| POST | `/admin/categories/{id}` | `name` `sortOrder` `_csrf` | 只改名称与排序 |
| POST | `/admin/categories/{id}/delete` | `_csrf` | 删除，有子分类或商品引用则 409 |

字段校验：`code` 1–32、`[A-Z0-9-]`、全局唯一、二级必须以 `-COMIC`/`-MERCH` 结尾；`name` 1–50、同级唯一；`sortOrder` ≥0。

### 3.3 商品

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/admin/products` | `categoryId` `keyword` `status` `page` `pageSize` | 列表（含下架） |
| GET | `/admin/products/new` | — | 新增表单 |
| POST | `/admin/products` | 见下 | 新增，默认 `DRAFT` |
| GET | `/admin/products/{id}/edit` | — | 编辑表单（携带 `version`） |
| POST | `/admin/products/{id}` | 见下 + `version` | 保存资料（库存只读） |
| POST | `/admin/products/{id}/status` | `status` `version` `_csrf` | 上架 / 下架 |
| POST | `/admin/products/{id}/restock` | `quantity` `_csrf` | 增量补货 |

商品表单字段：`sku` `name` `categoryId` `price` `stock`（仅新增）`summary` `description` `coverImage` `sortOrder` `status` `version`。

| 字段 | 规则 |
|---|---|
| `sku` | 1–40，`[A-Z0-9-]`，唯一，创建后不可改（编辑页只读） |
| `name` | 1–120 |
| `categoryId` | 必须是存在的二级分类 |
| `price` | >0，≤2 位小数，≤ `9999999999.99` |
| `stock` | 仅新增：≥0 整数；编辑页不出现该输入 |
| `summary` | ≤500 |
| `description` | 可空纯文本 |
| `coverImage` | 非空，≤255，站内路径 |
| `sortOrder` | ≥0 |
| `status` | 新增默认 `DRAFT`；只能经"上下架"动作变 `ON_SALE` |
| `quantity`（补货） | 1–100000 正整数 |

### 3.4 订单

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/admin/orders` | `orderNo` `status` `page` `pageSize` | 全站订单 |
| GET | `/admin/orders/{orderNo}` | — | 详情（含快照与凭证） |
| POST | `/admin/orders/{orderNo}/ship` | `_csrf` | 仅 `PAID` 可发货 |

### 3.5 用户与相册（P1；M08-04 / M08-05 已实现）

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/admin/users` | `keyword` `status` `page` `pageSize` | 只列 CUSTOMER |
| POST | `/admin/users/{id}/status` | `status` `_csrf` | 启用 / 禁用 |
| GET | `/admin/products/{id}/images` | — | 相册列表 |
| POST | `/admin/products/{id}/images` | `imagePath` `altText` `sortOrder` `_csrf` | 新增 |
| POST | `/admin/products/{id}/images/{imageId}` | `imagePath` `altText` `sortOrder` `_csrf` | 编辑 |

## 4. 统一参数口径

| 项 | 规则 |
|---|---|
| 页码 | 缺省 1；<1 的整数归一为 1；非整数/溢出 400 |
| 页大小 | 商品列表缺省 6，其他列表缺省 10；只允许 1–50 |
| 排序 | 仅 4 个白名单值，服务端映射到固定列，禁止拼接 |
| 类型 | 仅 `ALL/COMIC/MERCH` |
| 订单状态 | 仅 `ALL` + 五种状态 |
| 商品状态（后台） | 仅 `ALL/DRAFT/ON_SALE` |
| 搜索 | 去首尾空白；超长 400，不静默截断 |
| 布尔/枚举 | 大小写敏感，非法值 400 |

## 5. 提示文案（统一）

| 场景 | 文案 |
|---|---|
| 登录失败 | 账号或密码错误，或账号不可用 |
| 注册成功 | 注册成功，{用户名}，请登录 |
| 用户名占用 | 用户名已被占用 |
| 注册格式错误 | 用户名需为 3–32 位字母、数字或下划线 / 密码至少 8 位 |
| 未登录 | 请先登录（302 到登录页） |
| 越权 | 无权访问该内容 |
| 商品不可用 | 商品不存在或已下架 |
| 分类不可用 | 分类不存在或已停用 |
| 库存不足 | 「{商品名}」库存不足，仅剩 {n} 件 |
| 车已变化 | 购物车已变化，请刷新后重新确认 |
| 价格已变化 | 商品价格已变化，请重新确认 |
| 版本冲突 | 数据已发生变化，请刷新后重试 |
| 重复取消 | 该订单已处理，无需重复取消 |
| 重复支付 | 该订单已支付，请勿重复操作 |
| 状态不允许 | 当前订单状态不支持该操作 |
| 空车结算 | 购物车为空，请先选购商品 |
| 参数错误 | 请求参数不正确：{字段} |
